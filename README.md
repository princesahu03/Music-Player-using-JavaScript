# Music Player 🎵

A functional music player built using 
HTML, CSS, and JavaScript with smooth 
controls and clean UI.

## 🚀 Features
- Play / Pause controls
- Next & Previous track
- Progress bar
- Clean and responsive UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
